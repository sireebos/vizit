🏨 Quick Start Guide

Get Vermon Hotel & Bar up and running in 5 minutes

📖 Full Documentation: For detailed instructions, open documentation/index.html

Requirements

  • PHP 8.2 or higher
  • MySQL 5.7+ or SQLite
  • Composer 2.x
  • Required PHP extensions: BCMath, Ctype, JSON, Mbstring, OpenSSL, PDO, XML, Fileinfo, GD

Installation

Method 1: Installation Wizard (Recommended)

1 Upload Files

Upload all files to your web server's public directory

2 Set Permissions 
chmod -R 755 storage bootstrap/cache
3 Run Installation Wizard

Navigate to https://yourdomain.com/install

4 Access Admin Panel

Go to https://yourdomain.com/admin

Method 2: Manual Installation

# Install dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate app key
php artisan key:generate

# Edit .env with your database credentials
# Then run migrations
php artisan migrate --seed

# Create storage link
php artisan storage:link

Default Access

Admin Panel: /admin
Credentials: Set during installation wizard

Quick Configuration

Database (.env)

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database
DB_USERNAME=your_username
DB_PASSWORD=your_password

Hotel Settings (.env)

APP_NAME="Your Hotel Name"
CURRENCY=USD
CURRENCY_SYMBOL=$
TAX_RATE=10.00
