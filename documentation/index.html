Installation

Method 1: Installation Wizard (Recommended)

The easiest way to install Vermon Hotel is using the built-in installation wizard:

1
Upload Files

Upload all files to your web server's public directory (e.g., public_html or www).

2
Set Permissions

Set the following directories to writable (chmod 755 or 775):

chmod -R 755 storage
chmod -R 755 bootstrap/cache
3
Access Installation Wizard

Navigate to https://yourdomain.com/install in your browser and follow the steps.

4
Configure Database

Enter your database credentials (host, database name, username, password).

5
Create Admin Account

Set up your admin email and password for accessing the admin panel.

✓ Done! After completing the wizard, you can access the admin panel at /admin

Method 2: Manual Installation (Developers)

# Clone/extract files
cd your-project-folder

# Install PHP dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Configure database in .env file
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=your_database
# DB_USERNAME=your_username
# DB_PASSWORD=your_password

# Run migrations
php artisan migrate

# Seed initial content
php artisan db:seed

# Install frontend dependencies
npm install

# Build assets
npm run build

# Set permissions
chmod -R 755 storage bootstrap/cache

# Create storage link
php artisan storage:link

Configuration

Environment Variables

All configuration is managed through the .env file:

Variable Description Default
APP_NAME Your hotel name Vermon Hotel & Bar
APP_URL Your website URL http://localhost
APP_DEBUG Debug mode (set to false in production) true
DB_CONNECTION Database driver mysql
CURRENCY Default currency code USD
CURRENCY_SYMBOL Currency symbol $
TAX_RATE Tax percentage 10.00

Hotel Configuration

Hotel-specific settings are in config/hotel.php:

// config/hotel.php
return [
    'currency' => env('CURRENCY', 'USD'),
    'currency_symbol' => env('CURRENCY_SYMBOL', '$'),
    'tax_rate' => env('TAX_RATE', 10.00),
    'booking' => [
        'check_in_time' => env('CHECK_IN_TIME', '14:00'),
        'check_out_time' => env('CHECK_OUT_TIME', '11:00'),
        'advance_days' => env('BOOKING_ADVANCE_DAYS', 365),
        'cancellation_hours' => env('CANCELLATION_HOURS', 24),
    ],
];

CMS Features

Content Management Pattern

Each page uses a settings model with:

  • sections - Toggle visibility of each section
  • section_order - Drag-drop ordering
  • page_styles - Per-page color and CSS customization
  • content - Key-value JSON for all editable content

Image Handling

Always use the ImageHelper for image paths:

// In Blade templates
{{ \App\Helpers\ImageHelper::url($path, '/assets/img/default.jpg') }}

// Using the @imgUrl directive
@imgUrl($path, '/assets/img/default.jpg')

Reset to Default

  2. System shows available rooms with prices
  3. Guest selects room and enters details

Security

Envato Security Standards Compliant
This application follows all Envato security requirements.

CSRF Protection

All forms include CSRF tokens. Laravel's built-in CSRF middleware is enabled.

Role-Based Access Control

Using Spatie Laravel Permission package:

// Middleware usage
Route::middleware(['auth', 'role:admin'])->group(function () {
    // Admin routes
});

Password Security

  • Bcrypt hashing (12 rounds)
  • Minimum 8 characters required
  • Automatic hashing via model casting

Input Validation & XSS Protection

  • Server-side validation on all inputs
  • Blade templating auto-escapes output
  • SanitizeInput middleware
  • Security headers (X-Frame-Options, X-XSS-Protection, etc.)

Session Security

  • Encrypted sessions
  • HTTP-only cookies
  • SameSite cookie attribute
  • Session regeneration on login
  • Rate limiting on login (5 attempts/15 min)

FAQ

How do I change the logo?

Go to Admin → Site Settings → Upload your logo in the Logo field.

How do I add a new room type?

Go to Admin → Room Types → Add New. Fill in the details and save.

How do I change colors?

Go to Admin → Theme Settings → Color Scheme. Update colors and save.

How do I hide a section?

Go to the page editor, find the section, and toggle the visibility switch off.

Can I use SQLite instead of MySQL?

Yes! Change DB_CONNECTION=sqlite in your .env file and create a database.sqlite file in the database folder.

Troubleshooting

500 Server Error

  1. Check storage and bootstrap/cache permissions (755)
  2. Ensure .env file exists and is configured
  3. Run php artisan key:generate
  4. Check PHP version (8.2+ required)

Images Not Loading

  1. Run php artisan storage:link
  2. Check file permissions
  3. Verify image paths in database

Session/Login Issues

  1. Clear cache: php artisan cache:clear
  2. Clear sessions: php artisan session:clear
  3. Check SESSION_DRIVER in .env

Clear All Caches

php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
